# LRU Bot - Projet 2024-2025 - Cerise Sans Malediction

## Description
Bienvenue dans ce projet de **création d'un bot Discord en Js avec base de données**. Ce bot a pour but de pouvoir **attribuer un rôle** à chaque utilisateur lui donnant accès à **différents channels suivent ses groupes au sein de l'université**, mais aussi, l'utilisateur pourra avoir accès à ses **activité à venir sur Moodle**, son **emploi du temps depuis Discord**.

## Installation

>#### Prérequis :
- Avoir **Node.js** d'installé sur sa machine (https://nodejs.org/en).
- S'être créé **un bot Discord** (https://discord.com/developers/docs/intro).

>#### Pour installer le projet, il faut :
-  Tout d'abord, **télécharger notre projet sur GitLab** *si cela n'est pas déjà fait.*
- Ensuite lier son bot au projet téléchargé dans le fichier .env en suivant la template.
- Pour finir, **exécuter les commandes suivantes** dans le terminal à la racine du projet:
  - **npm install** (installation des packages)
  - **node src/app.js** (exécution du bot)

## Usage
Pour pouvoir utiliser ce bot, il faudra tout d'abord **effectuer la commande /login** sur le serveur où le bot se trouve pour pouvoir avoir accès à toutes ses fonctionnalités.
